# Panel icons

[Tabler Icons](https://tabler.io/icons) 3.34.0 (outline) and 3.49.0 (`*-filled`) by Paweł Kuna, MIT (`LICENSE`), and one Font Awesome Free 6.7.2 icon (`fa-solid-volume-high`, CC BY 4.0, its license comment kept inside). Unmodified copies of the desktop panel's icons in `internal/ui/icons/`, so the landing page's picture of the panel (`index.html`, `.dp-*` in `css/landing.css`) shows the same icons.

Used as `<span class="picon" data-picon="<name>"></span>`, with a `--picon` line in `css/landing.css` for each name. Copy any other one from `internal/ui/icons/`.
