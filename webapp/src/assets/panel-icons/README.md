# Panel icons

[Tabler Icons](https://tabler.io/icons) 3.34.0 (outline) by Paweł Kuna, MIT (`LICENSE`). Unmodified copies of the desktop panel's icons in `internal/ui/icons/`, so the landing page's picture of the panel (`index.html`, `.dp-*` in `css/landing.css`) shows the same icons.

Used as `<span class="picon" data-picon="<name>"></span>`, with a `--picon` line in `css/landing.css` for each name. Copy any other one from `internal/ui/icons/`.
